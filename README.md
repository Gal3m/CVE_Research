## At a glance

## Legend

## 1. OpenAPI / Swagger code generators

A systemic class of vulnerabilities: **untrusted content in an OpenAPI/Swagger document (names, defaults, paths, enums, docstrings, `$ref`s) is emitted into generated source code without sanitization**, so a malicious specification yields remote code execution, SSRF, file inclusion, or arbitrary file write in anyone who generates a client/server from it. Affected generators include orval, Refitter, kiota, go-swagger, oapi-codegen, fastapi-code-generator, jane-php, tapir, and openapi-python-client.

## Disclosure

All findings were reported to the respective maintainers under coordinated (responsible) disclosure and fixed, triaged, or acknowledged with them. This repository summarizes **advisory-level findings only** — it contains no exploit code or proof-of-concept. CVE identifiers for very recently published IDs may show as *reserved* or *awaiting analysis* on NVD until they are fully populated.
